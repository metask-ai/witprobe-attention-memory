# 论文2 数学规格(草案 v0.1,2026-07-31)

**这不是论文正文。** 本文件只定义对象、假设、以及**计划证明**的定理,用来回答一个问题:

> 一套"注意力记忆契约演算"是否真能覆盖我们已有的四类探针,并在真实模型上
> **组合出一个端到端的、非空洞的数字**?

判据很硬:**算不出端到端数字,就说明抽象层次不对**,那就该改抽象,而不是把定义写得更漂亮。
`(a,b)` 的仿射组合本身是经典结论(离散 Grönwall),单摆出来会被评为把平凡代数包装成理论;
它值得写的唯一理由,是让平台已有的分散读数变成**可组合的请求级风险**。

所以 §1 先做实例化,§2 才写通用形式。顺序是故意的。

## §1 先算一遍:DeepSeek-V4-Flash 的端到端组合

### 1.1 它的记忆通路

V4-Flash 一次写入-读取的实际顺序(实测,见 `experiments/out/p55_v4flash_attribution.json`):

```
x_1..x_B  --(U_pool: hc 门控加权)-->  c  --(U_store: fp8 量化落盘)-->  ĉ
                                                                       |
                        I = S(q, ĉ)  <--(索引器打分 + 页级 top-512)-----+
                                                                       |
                        y = R(q, ĉ, I)  <--(在选中页上做注意力)---------+
```

三段各自的性质**完全不同**,这正是需要契约而不是单一上界的原因:

| 段 | 是什么 | 引入误差吗 | 现有度量 |
|---|---|---|---|
| `U_pool` | 模型**自己的**计算(hc 门控池化) | **不引入** —— 它就是模型语义 | `a_pool=‖w‖_2`(sound)+ 集中度画像(经验) |
| `U_store` | 压缩(生产 fp8 + 我们的二次量化) | **引入**,有 sound 上界 | 带范数见证(p54/p55) |
| `S` | 稀疏选择(页级 top-512) | 不引入,但会**放大**:选错页 = 读错内容 | rank-prefix margin(p58) |
| `R` | 读出(注意力) | 不引入 | 论文1 的 TV 界 |

**第一个纠正**:此前把池化侧标为"纯经验、无契约",隐含地把它当成了误差源。它不是。
池化是 `U` 的一部分,在**未压缩**的 `x` 上执行 —— 真正的误差在其后的 `U_store` 才进入。
那池化在契约里扮演什么角色?**误差传递系数**。

### 1.2 池化的 sound 契约(新)

设块内 token 各自带误差 `Δ_j`(来自存储量化),门控权重 `w = softmax(s)`,`Σ_j w_j = 1`。
池化后的条目误差:

```
Δc = Σ_j w_j Δ_j
```

取块内 ℓ2 口径 `e_in := (Σ_j ‖Δ_j‖²)^{1/2}`,由 Cauchy–Schwarz:

```
‖Δc‖ ≤ ‖w‖_2 · e_in                          (P1)
```

于是池化的契约是 `(a_pool, b_pool) = (‖w‖_2, 0)`,且 **`‖w‖_2 ≤ 1` 恒成立**
(等号当且仅当某个 `w_j = 1`,即完全主导)。换句话说:

> **池化不是误差源,是误差的衰减器;衰减多少由"块内权重有多集中"决定,
> 而这正是 p55 已经在量的东西。**

若取块内 ℓ∞ 口径 `e_in := max_j ‖Δ_j‖`,则 `‖Δc‖ ≤ e_in`,即 `a = 1`(平凡但 sound)。
两个口径都要在论文里给出:前者更紧,后者不需要误差独立性假设。

**Lemma P1**(Cauchy–Schwarz,平凡)。写这一节时发现探针只量了 `top1_share`、归一化熵与
`exp(H)/block`,**没直接量 `‖w‖_2`** —— 而它才是契约系数本身。当即加进
`meters.pool_dominance` 并重跑 p55,得(2026-07-31,43 层四路同跑,EVERY=8):

| 通路 | block | 理论均摊下界 `1/√block` | **实测 `a_pool = ‖w‖_2` 中位** | 逐层区间 |
|---|---|---|---|---|
| 注意力侧 | 4 | 0.5000 | **0.5470** | [0.5062, 0.6752] |
| 注意力侧 | 128 | 0.0884 | **0.0911** | [0.0885, 0.1076] |
| 索引侧 | 4 | 0.5000 | **0.5459** | [0.5070, 0.6618] |

**几乎贴着均摊下界。池化把块内 token 的量化误差按 0.55×(block4)/0.09×(block128) 收缩。**

这推翻了写作前的判断(TinyKG 10499 曾推测池化可能是"认证断点"):方向正好相反 ——
它不是断点,是**整条链上最强的衰减器**。原因也清楚了:此前把池化当误差源,
而它在 `U` 里作用于**未压缩**的 `x`,本身不引入误差,只决定下游误差如何传递。

**这就是"写作反向暴露实验"的第一个实例,而且当场改掉了一个错判断。**

### 1.3 存储段:已有 sound 契约

带范数见证给出 `W = Σ_b ‖Δ_b‖ ≥ ‖Δ‖`(三角不等式),实测(43/43 层,92,791 行):

- 二次量化 int8 相对残差 **0.609%**(中位),见证保守度 `W/‖Δ‖ = **3.60×**,违约 **0**。

契约:`(a_store, b_store) = (1, W)`,其中 `W` 是逐 token 可算的见证。

### 1.4 选择段:rank-prefix 契约

严格 top-k 全集认证实测 **0.0355%** —— 近乎空洞。**这说明"整个 top-k 集合是否不变"
不是正确的问题。** 改问前 `r` 名是否稳定:

```
s_(r) − s_(r+1) > 2ε   ⟹   前 r 名在 |Δs| ≤ ε 下不变        (S1)
```

实测 top-1 认证率 **99.27%**(η=1e-3),`margin(r=1)` 中位 **1.946**。

但选择段的正确契约**不是**布尔的"变没变",而是"变了之后有多少注意力质量被换掉"。

**Lemma S2(已证,2026-07-31)**。把注意力分布视作在全键集上、选中集之外取 0。设原选中集
`I`、扰动后 `Î`,对应分布 `p`、`p̂`,则

```
TV(p, p̂) = ½Σ_i|p_i − p̂_i|
         ≤ ½( Σ_{i∈I\Î} p_i  +  Σ_{i∈Î\I} p̂_i )  +  ½Σ_{i∈I∩Î}|p_i − p̂_i|
         = ½(m_out + m_in) + TV_common(ε)                              (S2)
```

前两项是**被换出/换入条目的注意力质量**,第三项是公共集上的分数扰动项(沿用论文1 的
softmax 扰动机制)。于是选择段的契约是

```
(a_S, b_S) = ( 1, ½(m_out + m_in) )                                    (S2')
```

**关键结论:选择段是加性的,不放大上游误差** —— 它只添一项等于半数被换质量的偏置。

推 (S2) 时发现探针**只量了 m_out 没量 m_in**,当即补进 `meters.topk_margin` 并重跑。
实测(V4-Flash C4 索引器,21 层):

| η | m_out(中位) | m_in(中位) | **b_S(中位)** | 逐层区间 |
|---|---|---|---|---|
| 1e-3 | 0.00203 | 0.00203 | **0.00203** | [0.00096, 0.00521] |
| 1e-2 | 0.0203 | 0.0203 | **0.0203** | [0.0090, 0.0504] |

`m_out ≈ m_in` 是应当的:`|I| = |Î| = k`,边界处换出与换入的条目数相同、分数相近。
GLM(token 级 top-2048)同口径 `lost_mass` 小三个数量级(8.5e-6 @1e-3),
因为 k 越大边界处单条目的质量越小 —— **两个架构不可直接比,量纲不同**。

### 1.5 端到端组合(含一处结构纠正)

**纠正:`a_pool` 不属于基线链条。** 此前把组合式写成

```
e_end ≤ a_R·[ a_S·( a_pool·e_store_in + b_store ) + b_S ] + b_R      ← 错
```

隐含假设"误差在池化之前就已存在"。但 V4 的基线场景里压缩发生在**池化之后**
(`x → pool → c → 量化存储 → ĉ`),进入池化的 `x` 是精确的,`e_store_in = 0`,
`a_pool` 根本不在链上。正确的基线链条是:

```
e_end ≤ a_R·[ a_S·b_store + b_S ] + b_R
      = a_R·[ b_store + ½(m_out+m_in) ] + b_R          (a_S = 1)      (E1)
```

**那 `a_pool` 管什么?** 管**池化之前**的 token 级误差,两种真实情形:

1. **坏块/损坏**:某个 token 的贡献被破坏,经池化后按 `‖w‖₂` 衰减进条目 —— 这正好
   接上 §5 的哨兵:池化越均摊,单点损坏越被稀释,**也越难被下游察觉**。
2. **压缩位置的设计选择**:同样的逐 token 误差,压缩在池化**之前**比之后少 0.55×
   (block4)/ 0.09×(block128)。这是"证书引导的设计"的一个可检验实例。

写清这一点很重要:把 `a_pool` 硬塞进基线链条会得到一个**偏松且语义错误**的界。

**(E1) 各项的现状**:

| 项 | 值 | 来源 |
|---|---|---|
| `b_store` | 相对残差 0.609%(中位),见证保守度 3.60× | 已测(p54/p55) |
| `a_S` | **1**(加性,不放大) | Lemma S2 |
| `b_S` | **0.00203**(η=1e-3)/ 0.0203(η=1e-2) | 已测(§1.4) |
| `a_R, b_R` | 论文1 的 TV 机制 | 已有,但需 `q` 范数才能把 `b_store` 折成 TV |

### 1.6 请求级:契约演算把难点定位到了深度

一条请求要**穿过全部 43 层**,所以"请求级"必须把深度也按 (C1) 组合进来
(`experiments/out/p64_e2e_composition.json`):

| 层次 | 界(相对见证单位) | 判定 |
|---|---|---|
| 单层(中位 / 最大) | **0.0231 / 0.0291**(最差在 L42) | **非空洞**,远小于平凡界 1.0 |
| 请求级(43 层组合) | **0.982** | **边缘 —— 实质已接近平凡** |
| 平凡契约同样组合 | 43 | 我们的契约紧 **44×** |

**判据要留余量**:界只要逼近平凡上界(误差与信号同量级),实用上就已经没有信息。
故本文取 `<0.5` 才算非空洞、`[0.5,1)` 算边缘、`≥1` 算饱和 ——
把 0.982 说成"非空洞"技术上正确、实质上误导。

**正确的读法**:契约演算**成功地把难点定位到了深度**,而不是"我们给出了请求级证书"。

- 难点不在任何单段:单段贡献 0.023 量级,乘以 43 层才顶到 0.98;
- 这与论文1 的"跨层累积才是失效机制"是**同一件事**,现在用契约语言量化了;
- 要让请求级非空洞,需要某段 `a<1`(层间误差被平均/衰减)。池化的 `a_pool≈0.55` 正是
  这类系数,但它作用在池化**之前**的误差上,不在本链条里 ——
  **层间是否也有这样的衰减,是下一个要测的东西(推测,未验证)**。

前者是真结论且有用(它指出下一步该测什么),后者会是过度声称。

**结论:选择段与池化段的契约都已证且系数已实测,链条结构已厘清。**
唯一剩下的是把 `b_store`(带范数见证)按论文1 的机制折成 TV —— 那需要逐请求的 `q` 范数,
是一次测量而非一个未解的数学问题。

> 仍**不得**写"端到端 certified":`q` 范数未测之前,(E1) 只有选择段那一项是可直接引用的
> TV 数值(≤0.203% @η=1e-3)。
> 口径:`a_pool` 的 ℓ2 形式要求 `e_in` 按块内 ℓ2 聚合;ℓ∞ 口径下 `a_pool = 1`
> (平凡但无需任何假设)。两者都要报。

## §2 通用形式:注意力记忆契约

### 2.1 三算子抽象

任意注意力记忆写成:

```
m_{t+1} = U_t(m_t, x_t)        写入/更新
I_t     = S_t(q_t, m_t)        选择(可为全选)
y_t     = R_t(q_t, m_t, I_t)   读出
```

压缩或损坏后得 `m̂_t`。目标:由局部见证推出 `‖y_t − ŷ_t‖ ≤ E_t`。

**这把"支持新模型"从写适配器变成了明确的证明义务**:给出你的 `U/S/R` 及其局部契约,
平台负责组合。四类记忆都是它的实例:

| 记忆 | `U` | `S` | `R` |
|---|---|---|---|
| Dense KV | 追加 | 恒等(全选) | 注意力 |
| Latent KV | 追加 latent | 恒等 | 重建后注意力 |
| Sparse Selector | 追加 | top-k | 稀疏注意力 |
| Recurrent State | 递推 `S_t = A_t S_{t-1} + B_t` | 恒等 | 状态读出 |

### 2.2 契约三元组与组合律

每个组件出一个 `(a, b, δ)`:`e_out ≤ a·e_in + b`,失败概率 `δ`。

```
(a₂,b₂) ∘ (a₁,b₁) = (a₂a₁, a₂b₁ + b₂)          串联       (C1)
δ_req ≤ Σ_i δ_i                                  请求级预算  (C2)
```

`(C1)` 是仿射复合,平凡;`(C2)` 是 union bound。**它们本身不是贡献**,贡献是:

1. 把连续/离散/递归三类记忆纳入**同一个** `(a,b,δ)` 框架并给出各自的局部契约;
2. 显式区分 **certified / partially-certified / empirical** 三档,且这一区分是
   **机器可判定的**(平台的验收门就是它的实现);
3. 请求级风险如何跨异构组件组合,并能被运行时真正算出来。

### 2.3 三档的定义(要写进论文,因为它决定了什么能叫"证书")

| 档 | 定义 | 例 |
|---|---|---|
| certified | 存在 sound 上界,且实测非饱和(未退化为 `min(1,·)=1`) | 存储段带范数见证 |
| partially certified | 上界仅在可判定的子集上成立 | rank-prefix:仅 `margin>2ε` 的行 |
| empirical | 只有观测,无上界 | 池化的**集中度画像**(top1_norm/熵/eff);KDA 近 1 通道 |

**平台必须能报出每个数字属于哪一档** —— 这是本篇区别于"又测了几个模型"的地方。

## §3 递归状态:为什么均值不够(论文3 的种子)

现有 KDA 结论是逐层 `ā ∈ [0.530, 0.936]` 全部 < 1。但长期稳定性的正确判据是**乘积**:

```
e_t ≤ (Π_{i≤t} a_i)·e_0 + Σ_s (Π_{i>s} a_i)·b_s              (R1)
```

即 `Σ_t log a_t < 0` 才是条件,`ā < 1` 不是。且实测近 1 通道占 **0.03%–28.7%**,
这些通道上 `a→1`,逐通道契约不可回避:

```
e_{t,j} ≤ a_{t,j}·e_{t-1,j} + b_{t,j}                          (R2)
```

**已测(2026-07-31,`experiments/out/p65_kda_logsum.json`)**:

| 量 | 值 | 说明 |
|---|---|---|
| `E[log a]`(逐层中位) | **−0.5912** | 正确判据,全 20 层均为负 |
| `log(ā)`(逐层中位) | −0.2282 | 均值口径 |
| Jensen 间隙 | 0.3257 | `E[log a] ≤ log(ā)` 恒成立 |
| 半衰期(对数和) | **1.17 步** | 均值口径会报成 3.04 步 |
| 近 1 通道占比 | 中位 0.058 / 最大 0.137 | 其上 `log a≈0`,不收缩 |

**均值口径把收缩算弱了 2.6×** —— `ā` 既不是上界也不是下界,**它只是错的统计量**。

但**聚合的 `E[log a]<0` 推不出逐通道收缩**:当前 `E[log a]` 是对所有 (通道, 时刻)
样本的聚合,探针 reshape 后已丢失通道身份。**这是已知缺口**,严格结论需保留通道身份重测。

**论文2 的判决**:KDA 只报观测(上表 + 近 1 尾部),**不称证书**;
逐通道 `Σlog a_t` 与递归界留给论文3 —— 判据已明确,缺的是一次保留通道身份的重测。

## §5 采样哨兵的检测延迟保证(便宜且现成)

哨兵每轮只抽查部分槽位,故"何时发现坏块"本身可数学化。总槽位 `M`、坏块 `B`、
每轮抽 `r`、连续 `n` 轮:

```
P(n 轮全漏) = [ C(M−B, r) / C(M, r) ]^n                        (H1)
```

由此给出 SLA:**给定坏块数与抽样预算,以至少 `1−δ` 的概率在多少轮内发现故障**。

**已算(2026-07-31,`experiments/out/p52_sentinel_sla.json`)**:

- 最难情形(仅 1 个坏块、每轮抽 128/1024):**35 轮**内以 ≥99% 概率发现;
- 抽样预算是旋钮:`r`=32/64/128/256 分别需 **146 / 72 / 35 / 17** 轮,近似成反比;
- 与实测对拍:p52 的**有效轮数** n≈17(注入 rank 在注入之后的校验轮数),
  单块检出概率 **0.897**,"至多检出 2 个"的概率 **0.056** —— 实测 2/4 属正常涨落。

**算这一节时又被数据否掉一次参数假设**:最初用了 `verify_passes_total`=144,
那是**8 个 rank 的总和**,模型于是预测"4 个早该全找到",与实测直接矛盾。
正确的 n 是注入 rank 在注入之后跑过的轮数(≈17)。这也顺带**修正了一处过度声称**:
p52 记的"注入 4 槽位被逐槽定位"读起来像 4/4 全中(TinyKG 10418/10496)。

## 代际一致性:premise 升格与观测点类型(2026-08-02,case study 收口)

工程定谳(p118→p124c,正文 §Closing the boundary)反哺两条到契约层:

**1. (slot, generation) 是 contract premise,不是日志字段。**

refinement 义务:**消费条目的代际 = 授权时的代际**;enforcement 半边 =

`formal/standalone/Generation.lean` ——
- `stale_consume_reachable`:无失效纪律下跨代消费是**可达状态**(最小迹

- `run_fresh`:失效纪律(源写与失效原子成对)下,新鲜性不变量沿任意事件迹
  保持,消费值恒等于当前源值,**零公理依赖** —— 正确性由不变量承担,
  不押注"首见即终态"等经验事实。

**2. 观测点(observation site)是 metric 类型的一部分。**
数学上同一指标(packed vs 源的相对误差)在写回站点对本失效**零区分度**
